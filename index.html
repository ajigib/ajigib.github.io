def gc_content(seq):
    gc = seq.count("G") + seq.count("C")
    return gc / len(seq)

def find_hgt_candidates(genes, donors):
    hits = homology_search(genes, donors)
    for gene in genes:
        index = hgt_index(hits[gene])
        if index > THRESHOLD:
            yield gene, index

def enrich(gene_set, background):
    p = hypergeom_test(gene_set, background)
    return fdr_correct(p)

def synteny_blocks(anchors, gap=50_000):
    blocks, cur = [], [anchors[0]]
    for a in anchors[1:]:
        if a.pos - cur[-1].pos <= gap:
            cur.append(a)
        else:
            blocks.append(cur); cur = [a]
    return blocks + [cur]

Research

Data & quality control

Getting trustworthy genome data before any analysis begins.

  1. Genome assembly — a genome sequence reconstructed by stitching sequencing reads into longer pieces.
  2. Contiguity (N50) — a measure of how long the assembled pieces are; longer pieces mean fewer breaks and gaps.
  3. Completeness — how many of the genes expected in every member of a group are actually present.

Synteny & breakpoints

Comparing gene order between species to see how chromosomes were rearranged.

  1. Synteny — conservation of gene order along chromosomes between species.
  2. Synteny block — a stretch of genome where genes keep the same order and orientation.
  3. Evolutionary breakpoint — a point where that order is broken by an inversion, translocation, fission or fusion.

HGT detection

Finding genes that entered a genome from another species rather than from a parent.

  1. Horizontal gene transfer — movement of genetic material between organisms outside normal parent-to-offspring inheritance.
  2. Donor and recipient — the lineage a gene came from, and the genome that received it.
  3. Alien index — a score comparing similarity to distant versus close relatives; foreign genes look closer to distant ones.

Ancestral genome

Inferring what the genome of a long-gone common ancestor may have looked like.

  1. Ancestral reconstruction — estimating the genome organisation of a common ancestor from its living descendants.
  2. Outgroup — a more distant relative used to tell ancient features from newly evolved ones.
  3. Ancestral fragment — a stretch of chromosome inferred to have been intact in the ancestor.

Repeats & function

Understanding the repetitive DNA that shapes genomes and what genes do.

  1. Transposable element — a DNA sequence that can copy itself or move to new places in the genome.
  2. Repeat masking — marking repetitive sequence so it does not confuse gene and alignment analysis.
  3. Functional enrichment — testing whether a gene set is unusually rich in particular pathways or functions.

Statistics

Telling a real biological pattern apart from chance.

  1. Permutation test — comparing an observed value with many random rearrangements of the same data.
  2. Odds ratio — how many times more likely an outcome is in one group than in another.
  3. Multiple-testing correction — adjusting significance when many tests are run, to limit false positives.
